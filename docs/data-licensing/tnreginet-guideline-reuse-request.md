# Request for permission and authorized access to TNREGINET guideline-value data

**To:** Inspector General of Registration  
Registration Department, Government of Tamil Nadu  
No. 100, Santhome High Road  
Chennai – 600028

**Subject:** Request for written permission and authorized data access for public-interest guideline-value publication

Dear Sir/Madam,

MITO is an evidence-backed land-intelligence platform being developed to help citizens understand Tamil Nadu land values without confusing government guideline values, registered transactions, asking prices or model estimates.

For the OMR pilot, we have used the normal public interface to verify metadata-only inventory totals for 24 registration villages from Adyar to Mamallapuram. The current register displays 2,715 items across those villages. We have not stored or republished the row-level register content.

We request written permission to collect, normalize and republish the following non-personal fields from the public TNREGINET guideline-value register:

- zone, registration district and sub-registrar office;
- guideline village and revenue-village identifiers;
- street name and official street identifier, where available;
- guideline value in the original unit and normalized rupees per square foot;
- land classification;
- effective start and end dates; and
- source and government-order references.

We also request access to an authorized bulk export or documented API, if available, so that the data can be collected accurately without placing unnecessary load on the public website.

MITO will:

- attribute the Registration Department on every published record;
- link users back to TNREGINET and show the source and verification dates;
- preserve corrections, conflicting evidence and historical values;
- never label guideline value as confirmed market price;
- avoid publishing personal information, deeds, signatures or restricted documents;
- leave locations unplotted when street or parcel geometry is not officially verified; and
- comply with any approved update cadence, display rules, access controls and takedown requirements.

Please confirm:

1. whether row-level guideline values may be republished with attribution;
2. whether street-level aggregates and derived statistics may be published;
3. the permitted update frequency and redistribution format;
4. whether an official export, API or data-sharing process is available;
5. whether official street identifiers and historical effective dates can be supplied; and
6. the correct contact for data corrections and licensing questions.

No TNREGINET row-level register will be republished by MITO until written permission or an applicable licence is confirmed.

Sincerely,  
MITO — Tamil Nadu Land Intelligence
